# Mai-SalesAi

AI sales training and coaching tools.

## Folders

- **`train-method/`** — The TRAIN Method sales training widget — generic, no industry-specific content, includes full/coached roleplay, live call listening, demo upload, phase scoring and manager view.
- **`richards-widget/`** — Richards Supply edition widget with timing fix and Demo Analysis (Teams MP4 support).
- **`competitive-research/`** — AI sales coaching competitive scrub (October 2026).

The root `app.py`, `requirements.txt` and `templates/` contain the existing Flask app.
